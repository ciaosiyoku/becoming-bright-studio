# Installing Becoming Bright Studio

**What it is:** a web app. It works in the browser and does not block other apps. Installing it puts an icon on
the home screen, so it opens like an app and the browser keeps its data.

The easiest way: open **https://ciaosiyoku.github.io/becoming-bright-studio/install.html** on the tablet. The page
recognises the device and shows only its steps. On a computer, scan the QR code on that page with the tablet's
camera.

There is no app store, no account and no download of personal data.

## Android tablet or phone (and Amazon Fire)

1. Open the install page in **Chrome** (on a Fire tablet: **Silk**, in the parent profile).
2. Tap the menu (⋮) and choose **Install app** or **Add to Home screen**.
3. Open Becoming Bright Studio from the home screen and follow the setup.

## iPad or iPhone

1. Open the install page in **Safari**.
2. Tap **Share** (a square with an arrow) → **Add to Home Screen** → **Add**.
3. Open the app from the home screen and follow the setup.

For a better reading voice on iPad: **Settings → Accessibility → Spoken Content → Voices**, and download an
"Enhanced" voice.

## Keeping a child in one app

The app can't do this, and doesn't claim to. If you want it, use the device's own setting:

- **iPad:** Settings → Accessibility → **Guided Access** → On, then triple-click the top (or home) button inside the app.
- **Android:** Settings → Security → **App pinning** (some devices: "Screen pinning"), then pin the app from the
  recent-apps view.

A bedtime lock or a home-screen lock would be a native app: a different, later product.

## First start

The setup asks for the child's first name or nickname and a colour, then a **4-digit PIN** for grown-ups, and shows
a **recovery code** once (write it down or print it). More children can be added later on the grown-ups' screen.

## Backups and moving to a new device

Data lives only on the device. Save a backup now and then: **Grown-ups → Backup → Save a backup** (the app reminds
you once a week). On a new device, install the app, set it up, and use **Restore from a backup**. The backup file
holds the children's names and progress, but never the PIN.

**Forgot the PIN?** Use the recovery code. Without it, choose **Start again from a backup**: the device is replaced
by the backup and you choose a new PIN. There is no "reset after 24 hours".
